# 赛马娘 Pretty Derby · 训练员登录页（纯前端边缘计算演示）

单文件网页，**不依赖任何服务器、CDN 或外部接口**：校验、加密摘要、状态存储、动画渲染全部在你当前浏览器（边缘端）完成，断网也能用。

## 打开方式

直接双击 `index.html`，或拖进浏览器地址栏（`file://` 协议即可）。

## 功能

- **登录 / 首次注册**：训练员 ID 2–20 字符（中英文、数字、下划线、连字符），密码至少 6 位；首次登录自动在本机建立训练员档案。
- **密码安全**：只保存加盐摘要（`SHA-256(uid|salt|password)`，WebCrypto 不可用时回退 FNV-1a），明文密码不落盘、不外发。
- **记住训练员 ID / 显示密码 / 访客快速体验**。
- **登录后大厅**：登录次数、上次登录时间、节点设备、外部请求计数（固定 0 次）。
- **边缘节点信息面板**：渲染引擎、CPU 逻辑核心、设备内存、语言/时区、屏幕、存储后端与用量、本机 `uma.*` 数据键、清除本机数据。
- **演示模式**：`index.html?demo=hall` 或 `index.html#hall` 直达大厅；`index.html?demo=edge` 或 `index.html#edge` 直达边缘节点面板。
- 响应式布局（手机竖屏可用）、`prefers-reduced-motion` 降级、花瓣/光晕/跑道等纯 CSS 动画。

## 数据与隐私

- 账号与状态只存在当前浏览器的 `localStorage`（键名前缀 `uma.`），换浏览器或清除站点数据即丢失，没有云端同步。
- 这是**演示页面**：请勿输入真实密码、真实账号信息。
